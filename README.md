# Carbon Footprint Calculator with AI Sustainability Advisor

## 📌 Project Overview

A web-based Carbon Footprint Calculator designed to help organizations measure, analyze, and monitor their carbon emissions.

The system allows users to enter operational data and calculate emissions across different emission scopes, while providing sustainability insights and recommendations.

## 🎯 Project Goal

The main goal of the project is to provide a simple platform for tracking carbon emissions and supporting data-driven sustainability decisions.

## 🚀 Key Features

- Branch and company management
- Carbon emissions calculation
- Scope 1, Scope 2, and Scope 3 tracking
- Emission source analysis
- Dashboard with key performance indicators
- Reports and emission summaries
- AI Sustainability Advisor
- Risk level and priority assessment
- User authentication and access control
- MySQL database integration

## 🛠️ Technologies Used

- PHP
- MySQL
- HTML
- CSS
- JavaScript
- Bootstrap
- AdminLTE
- Chart.js
- XAMPP

## 👨‍💻 My Role

**Data & System Analyst**

I worked on data handling, database integration, system analysis, dashboard development, and implementing the carbon emission calculation and reporting features.

## 📊 Project Output

The system provides an interactive dashboard that helps users understand:

- Total carbon emissions
- Emissions by scope
- Main emission sources
- Branch performance
- Risk levels
- Sustainability recommendations

This project was developed as part of a banking internship project, focusing on using technology and data to support carbon emissions monitoring and sustainability analysis.
